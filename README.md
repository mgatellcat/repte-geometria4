# 📐 Repte de Geometria · 4t de primària

Web app interactiva per repassar geometria de 4t de primària: línies i rectes, polígons, elements d'un polígon, triangles i quadrilàters. Inclou cinc missions i un examen final amb nota.

Funciona a l'ordinador, amb ratolí o pantalla tàctil. És un sol fitxer (`index.html`), sense dependències.

Cada vegada que s'obre, demana el **nom de l'alumne** i guarda les estrelles i la millor nota de cada nom per separat (al mateix navegador). Els noms que ja han jugat surten com a botons per entrar amb un sol toc.

El **📖 Recorda** (resum de la llibreta) és a la vista: un bàner a la pantalla inicial, un botó a cada missió, s'obre sol la primera vegada que es comença una missió, i apareix quan s'erra una pregunta o en acabar.
